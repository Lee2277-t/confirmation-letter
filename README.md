# 函证助手

从往来余额表里挑出要函证的单位，生成**函证控制表**（Excel）和**询证函**（可打印）。

单页 HTML，解压后双击 `index.html` 就能用。不用装、不用联网，**文件只在浏览器里读，不上传任何地方**。

---

## 它解决什么

函证这个环节，实习生最常做的事是：从客户的往来明细里挑出要发函的单位 → 一个个做成询证函 → 再登记发函回函。

手工做的问题不是慢，是**容易漏和容易错**：

- 挑的时候凭感觉，事后说不清为什么挑这几家
- 同一家客户挂了三个科目，函却只发了其中一个的金额
- 台账和函对不上，回函回来了找不到对应哪一户

这个工具把「挑」和「出函」两步固定下来，留下的痕迹能写进底稿。

---

## 怎么用

### 1. 上传往来余额表

需要**一列单位名称**（客户/供应商）和**一列期末余额**。科目、账号有的话会一起带出来，写进函里。

能认的列名包括：单位名称 / 客户名称 / 供应商名称 / 往来单位 / 户名、期末余额 / 余额 / 金额。表头在前 20 行内都能找到。

> 没有文件可以先点「用示例数据试一下」，示例是虚构的。

### 2. 选样

| 口径 | 说明 |
|---|---|
| 大额全要，其余随机补足 | **推荐**。超过门槛的全部发函，剩下的随机补齐 |
| 只要超过金额的 | 纯阈值 |
| 纯随机抽 | 不看金额 |
| 全部都要 | 小额也要函 |

**随机种子**：同一个种子抽出来的是同一批。写进工作底稿，复核的人能重跑出一样的结果——这比"我是随机抽的"有用得多。

### 3. 核对后生成

列表里每一户都能取消勾选（比如已经结清、或者对方是小额关联方）。

- **函证控制表（Excel）**：序号、被函证单位、科目、账面余额、函证金额、选样方式，后面留了发函日期、回函日期、回函金额、差异、差异说明五列
- **询证函（打印版）**：一户一页的 HTML，浏览器打开后 Ctrl+P 打印，或另存为 PDF

## 它不做什么

说清楚边界，比吹功能有用：

- **回函登记和差异调节要你自己填**。控制表里那几列是空的，不预填假数据。
- **银行询证函有固定格式**（含银行存款、借款、担保、票据等十四项），这个工具出的是**企业往来款项**的通用格式，不替代银行询证函模板。
- 不做函证程序设计（发多少、发哪些），那是项目组的判断；它只把你定的口径执行到位。
- 不做替代程序。

## 几个设计上的取舍

**金额一律按分算。** 内部用整数分，显示才转成元，不会出现 `0.1 + 0.2 = 0.30000000000000004`。

**同名单位合并。** 一家客户挂应收账款和预收账款，函是发给这个单位的，金额就该合在一起。科目会在函里列全。

**读不出的行不丢。** 金额是「待核实」这种文字、或者有金额没单位名称的行，会单独报出来并说明原因，不会悄悄跳过——悄悄跳过的结果是底稿少一笔钱，而没人知道。

**`12,34` 这种不认。** 千分位只认「每三位一组」。`12,34` 到底是 1234 还是 12.34，猜错就是一笔钱的差错，宁可不认，报出来让人看。

**合计行自动跳过**，不当成一家单位。

## 文件说明

```
index.html      入口，双击打开
core.js         纯逻辑：认表、选样、出函（可单独测试）
app.js          界面
app.css         样式
vendor/         SheetJS（离线，读 xlsx）
test/           回归测试
```

跑测试：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File test\run-all.ps1
```

打发布包：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File test\pack.ps1
```

## 数据安全

所有处理都在你自己的浏览器里完成。没有后端，没有埋点，没有上传。

**但请注意**：工具会生成**真实的询证函文件**，里面有客户的单位名称和金额。这些文件按你所在单位的保密要求管理，不要随手发到不该去的地方。

---

## 已知限制

- 只认「一列名称 + 一列金额」的平面表。多维表头（两级合并）、透视表、带辅助核算展开的导出格式，可能认不出来——认不出时工具会说"找不到可认的表"，不会硬猜。
- 询证函是简体中文、A4 的通用版式。要套事务所模板的话，改 `core.js` 里的 `letterHTML`。
- 一次处理一个文件的一张表。
